多设备同步（可选，强烈建议配置）

配置后，任意设备（Mac/iPad/iPhone）的学习进度自动合并互通——数据存放在你自己的 GitHub 私有仓库 study-progress，他人不可见。每台设备都需完成一次本配置（粘贴同一个 Token）。

推荐的完整学习循环

  1. 进课程页「① 预习」：花 5 分钟读预习卡，点「开始学习」进入讲义精读本章；
  2. 读完正文立刻做「④ 测试」的自测问答，诚实标记答对/答错；
  3. 合上讲义去「③ 案例解析」先自己想，再展开解析对照；
  4. 「⑦ 刷题」按章刷选择题，错的题自动进错题本，考前用「错题重练」；
  5. 每天打开门户看「今日待复习」，按间隔重复回看；考前过一遍「⑤ 考试备考」的速记清单。

进度保存在本浏览器的本地存储中——请始终用同一个浏览器打开各页面，进度即可互通。

课程内容基于指定教材整理，用于个人学习；示例数字均为教学设计。门户与课程页通过浏览器本地存储（localStorage）同步进度；配置「多设备同步」后经 GitHub 私有仓库跨设备互通。
